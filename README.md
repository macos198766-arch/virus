# Мой первый сайт

Этот проект создавался в качестве продукта к моей курсовой работе на тему "Компьютерные вирусы" за первый курс колледжа. В нем собрана базовая информация о вредоносном ПО и методах защиты от него. 
Целью сайта стали:
1. Обучение frontend-разработке с нуля
2. Повышение цифровой грамотности у пользователей ПК

## Технологии

1. HTML
2. CSS
3. JavaScript, в том числе библиотека Swiper
4. Flexbox/grid - сайт корректно отображается на любых устройствах
